Included below are the instructions for installing python, as you will not want to use the standard /bin/python installation on the SCRTP. I've split it into sections covering commands (indicated by a leading > ) you will need to run once only, and commands you will need to run with every terminal session.

===== SCRTP first time only =====

cd to your user area on /storage and create a python directory. For me this would be

> cd /storage/epp2/phrdqd
> mkdir python
> cd python

Next we need to install virtualenv to be able to create our own Python environment that we can modify to suit ours needs:

> pip3.6 install --user virtualenv

To ensure that this version of virtualenv runs, add its location to your PATH environment variable

> export PATH=~/.local/bin/:$PATH

Now we can create our Python environment, which I shall call 'project'

> virtualenv project

This should create a project directory within your current directory. We can activate the project environment via (modifying the path as needed for your installation location):

> source /storage/epp2/phrdqd/python/project/bin/activate

You should see (project) appear in your command prompt, and if you now run

> which python

you should see something similar to. If it's just /bin/python, something has gone wrong

/storage/epp2/phrdqd/python/project/bin/python

At this stage you probably want to run some small scale interactive tests of your code, which will likely fail due to missing modules. As we are working in a custom environment, you're free to install these modules in the usual way with pip. Once you've installed all of the modules, any time you activate this environment in the future, they'll be available for your use.

Should you need to deactivate the current environment:

> deactivate

Or alternatively, opening a new terminal will revert to the default /bin/python installation.

===== End SCRTP first time only =====

===== Every new terminal/command prompt session =====

Any time you open a new terminal and want to use this environment, you'll need to activate it via:

> source /storage/epp2/phrdqd/python/project/bin/activate

Now if you run

> python my_script.py

Your script should run in this environment
 
===== End every new terminal/command prompt session =====
